# 绘域全量重构实施计划

## 阶段 1：基础边界

1. 建立 `frontend/`、`backend/huiju/`、`ops-dashboard/`、`var/` 目标目录，先将资源服务、应用组合、模型目录的职责抽离。
2. 固化现有 API 行为测试，删除只断言源文件字符串的测试。
3. 统一运行目录配置，生产数据保持原位置直到迁移验证完成。

## 阶段 2：后端

1. 将应用装配、资源服务、边缘服务分别移至 `backend/huiju/api` 与 `backend/huiju/edge`。
2. 抽取 `catalog`，使 `/api/v1/bootstrap`、`/api/v1/models`、`/api/v1/capabilities` 共享同一输出。
3. 按生成、素材、工作流、账户、积分拆分路由依赖；之后删除旧聚合路由。

## 阶段 3：前端

1. 以工作台为先，将启动、请求、状态、统一创作入口和素材上传迁入 ES Modules。
2. 拆分样式 token、布局、组件与 feature 样式。
3. 迁移工作流、素材、账户和发现页面；删除旧根目录脚本与样式。

## 阶段 4：清理与发布

1. 将有效运行数据迁至 `var/`，验证完成后删除旧 JSON 读取实现。
2. 删除兼容启动包装、旧缓存转换、旧工作流映射与重复目录。
3. 执行后端 API、前端模块、浏览器冒烟和发布前健康检查。
