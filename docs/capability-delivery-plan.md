# 未实现能力交付规划

## 目标

将侧栏中尚未交付的能力拆成可复用服务，而不是为每个入口各写一套实现。每项上线前必须同时通过：接口契约、真实模型任务、产物检查和页面交互检查。

## P0：状态与入口真实性

- AI 生图：已修正为任一已配置的图像生成服务可用即显示“可直接用”。
- 模型目录：未配置模型只留在模型选择器的“待接入”状态，不再作为一级侧栏功能。
- 验收：页面不出现可点击却无路由的入口；每个“可直接用”入口均能创建对应任务。

## P1：复用现有模型或轻量服务

| 能力 | 实现 | 复用范围 | 验收 |
| --- | --- | --- | --- |
| 无损放大、效果图超分 | 单一服务器轻量超分服务 | 图像编辑、建筑室内 | 2x/4x 输出尺寸正确；文字、边缘和主体不漂移 |
| AI 抠图 | 轻量 Alpha 抠图服务，输出透明 PNG | 商品换背景、资产库、工作流 | 透明通道存在；发丝/商品边缘无明显白边 |
| 角色设定稿、游戏场景、道具设计 | 用已接入 Qwen/Wan 图像模型的结构化提示词和模板 | 游戏动漫 | 设定稿含正侧背/细节；场景与道具符合功能名 |
| 分镜成片 | 现有图像/视频任务编排，加 FFmpeg 合成 | 短剧工坊、工作流 | 分镜顺序、时长、音轨与成片预览一致 |
| 视频配音 | 抽取音轨、ASR、旁白草稿、TTS、混音回写 | 配声工坊、短剧工坊 | 输出视频可播放；旁白时序与镜头内容匹配 |

## P2：专用模型或专项管线

| 能力 | 前置条件 | 实现与验收 |
| --- | --- | --- |
| 交互编辑、图层拆分 | 开通 Seedream 5.0 Pro | 点/框坐标直传；最多 16 张透明图层可下载、复用和进入工作流 |
| AI 二维码 | 二维码编码器与受控图像生成 | 每次生成后自动扫码；扫描失败即判定测试失败 |
| 转深度图 | 独立异步推理环境，不常驻占用生图显存 | 输入视频帧数、帧率、分辨率与深度序列一一对应 |
| 爆款复刻 | 获得素材权利确认；抽帧、ASR、视觉理解、分镜规划 | 输出可编辑的镜头结构和重制提示，不复用原始视频内容 |

## P3：按真实需求开启的模型槽位

| 范围 | 策略 |
| --- | --- |
| Z-Image、Qwen-Image-2512、FLUX | 只有本地模型服务可稳定启动、显存预算明确时才启用 |
| Seedream 4/4.5/5/5 Pro | 开通对应 API 后，先完成文生图、多参考图、交互/图层的单项真实测试再开放 |
| GPT Image 2、MiniMax H3 Max | 确认第三方计费、内容策略和额度价格后接入；现有 Wan/Seedance 已覆盖基础生图、生视频需求 |

## 特殊处理

- AI 换脸不进入普通编辑链路。只有确认肖像授权、用途审计和供应商能力后才单独开放。
- 所有带上传素材的云视频能力都依赖 `HUIJU_PUBLIC_BASE_URL` 指向可从公网访问的 HTTPS 应用域名。

## 建议交付顺序

1. 轻量超分和抠图。
2. 游戏动漫三项模板与分镜成片。
3. 视频配音与转深度图。
4. Seedream 交互编辑/图层拆分、AI 二维码。
5. 按需求接入额外模型；AI 换脸最后单独立项。
